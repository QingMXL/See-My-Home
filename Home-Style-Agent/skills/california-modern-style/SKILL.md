# California Modern styling

This skill defines the selected aesthetic. It does not authorize architectural changes.

Before generating, read:

1. `references/style-schema.yaml` for the selected profile, style DNA, material hierarchy, room rules, density target, and anti-patterns.
2. `references/prompt-components.md` for the model-facing English components and assembly order.

Use only the profile and room recipe named by the runtime request. Default to `sunlit-casual`.

The result must read as a complete California Modern home, not an empty beige room. Make natural light lead; establish a warm mineral envelope; use one coherent oak family, one grounded honed-stone or terracotta note, at least two tactile textile layers, comfortable low horizontal furniture, and one vintage-inspired or handcrafted counterpoint. Furnish every functional zone while retaining visual breathing room.

Design the ceiling as part of the room. Preserve the structural slab plane, ceiling height, beams, columns, and window or door heads exactly. Within the editable finish scope, use a shallow perimeter reveal or cove, warm indirect light, a simple sculptural pendant where room function supports it, and practical task or face-level lighting. Two isolated downlights are not a complete lighting scheme.

Never put research sources, studio names, designer names, or style-transfer attribution in a production image prompt. Describe the observable design language.

The runtime immutable scope is absolute. Preserve both visible edges, silhouette, apparent width, and image-border position of every column and beam, plus all walls, openings, camera geometry, aspect ratio, and crop. Decorative cladding may change appearance but not geometry.

Avoid farmhouse, nautical coastal theming, boho overload, all-pale-wood Japandi, sterile showroom staging, hotel-lobby scale, invented fireplaces or beams, and architecture changes.
