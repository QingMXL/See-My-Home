## What is See My Home?

See My Home turns the three hardest conversations at the beginning of a residential design project—**how the space works, which style fits, and what custom furniture should become**—into visual proposals that clients can see, compare, and refine.

Instead of asking clients to understand professional drawings or write a complete prompt, the product gathers intent through floor plans, room photos, references, tags, dimensions, and guided controls. Three dedicated AI Agents then turn that information into client-ready visuals, helping independent designers align on direction earlier and reserve more time for the decisions that need professional judgment.

## One workspace, three design decisions

| Agent | The question it answers | Main input | Main output |
| --- | --- | --- | --- |
| **Home Layout** | “What will this floor plan feel like to live in?” | Floor plan, room functions, household and lifestyle needs | Colorized furnished plan and spatial assessment |
| **Home Style** | “What will this style look like in my home?” | Room photo, style preset or reference image, revision notes | Structure-preserving styled room image and design explanation |
| **My Furniture** | “How can this furniture idea become discussable?” | Sketch, inspiration image, text, dimensions and material preferences | Concept render, base specification and dimensioned orthographic views |

### Home Layout — translate building scale into living scale

Home Layout converts a professional black-and-white floor plan into a colorized top-down view with furniture and materials, helping clients understand the room arrangement at a glance. Behind the image, it identifies rooms and openings, builds a revisable Home Model, calibrates available scale, and plans furniture, circulation and material zones without treating generated pixels as structural truth.

### Home Style — turn vague preferences into something visible

Home Style applies a selected design language directly to the client's own room. It supports Modern East, California Modern, Maximal Luxe, and a custom-reference route, while preserving the original walls, openings, columns, camera position and spatial proportions. Clients can compare real directions in a familiar space instead of relying on phrases such as “warmer,” “more modern,” or “premium but not cold.”

### My Furniture — turn an idea into a shared design reference

My Furniture starts from a rough sketch, an inspiration image, written intent, or a combination of them. It resolves the idea into a structured furniture specification and concept render; after confirmation, it creates front, side and top views on one consistent dimensional basis. The result gives clients, designers, suppliers and factories a shared reference for further development and prototyping.

## A shared product flow

All three experiences use the same interaction pattern:

```text
Upload material → Confirm key information → Generate → Review and explain → Refine, save or download
```

The interface uses images, presets, tags and parameters to collect structured intent first, leaving free text for details and later revisions. Each Agent remains independently versioned, tested and deployable behind the shared UI.

## Architecture

```text
See My Home Web UI
  → isolated /api/home-layout, /api/home-style, /api/home-furniture routes
  → dedicated ZooWork managed Agent + versioned Skills
  → validated and published visual artifact
```

- The browser never receives the ZooWork API key or calls ZooWork directly.
- Each Agent has its own Runtime contract, API namespace, Agent ID, Skills, schemas and tests.
- Private uploads and generated images use Vercel Blob; Agents receive short-lived signed references.
- [`agent-release.json`](./agent-release.json) pins the compatible Agent versions used by the product.

See [Agent integration and release policy](./docs/AGENT-INTEGRATION.md) for the complete runtime contract.

## Run locally

Requirements: Node.js 20 or newer and pnpm.

```bash
pnpm install
pnpm check
pnpm test
pnpm build
pnpm dev
```

To test the three ZooWork Runtimes locally:

```bash
pnpm --dir Home-Layout-Agent test:local
pnpm --dir Home-Style-Agent runtime
pnpm --dir Home-Furniture-Agent runtime
```

Copy the relevant `.env.example` files to ignored `.env` files and add your own server-side credentials. Never expose a ZooWork API key through browser code or a `VITE_*` variable.
