## 下载前检查

- 仅从原始项目页取图，不从 Pinterest 或搜索结果保存。
- 记录摄影师和版权声明；若页面禁止下载，不绕过限制。
- 不将第三方图片提交到公开 Git 仓库。
- 如仅获内部许可，放入受控资产存储而不是应用静态目录。
