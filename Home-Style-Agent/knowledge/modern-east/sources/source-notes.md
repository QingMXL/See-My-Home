# Modern East 研究来源与权重

访问日期：2026-09-04

## 1. 研究方法

1. 先以事务所官方设计理念建立理论词汇。
2. 再筛选住宅、大平层、顶层复式和住宅样板间案例。
3. 对图片进行房间级观察，记录空间、材质、色彩、家具、灯光和风险。
4. 仅将多个项目反复出现的特征提升为“核心规则”。
5. 单个项目中的强烈造型、主题色或艺术装置只作为子风格或风险样本。

“证据权重”表示该来源对当前知识库的贡献程度，不表示事务所或项目质量。

## 5. 跨案例共识

### 高置信度

- 东方性来自空间秩序、观看方式、自然和情绪，而不是符号堆积。
- 深色木与浅色石材是重要的冷暖、轻重对照。
- 留白和少量艺术焦点共同工作。
- 光影是材料与空间的组成部分。
- 家具形态现代，常以低重心、圆角或雕塑感软化建筑线面。
- 屏风/框景用于制造层次和半透明关系。

### 中置信度

- 圆形或椭圆餐桌强化聚合与仪式感。
- 古铜、香槟铜和发黑金属适合小比例细节。
- 灰绿、玉色和橄榄绿可作为自然联想的点缀。
- 轻微 Art Deco/海派线条可用于 `urban-elegance`。

### 不应提升为核心

- 巨型装置灯具和复杂天花。
- 四柱床、壁炉、旋转楼梯、下沉空间。
- 大面积强纹理大理石。
- 酒吧、酒窖、雪茄室和双客厅。
- 高饱和海蓝、橙色或明确地域主题色。
- 大量收藏级艺术品和奢侈品陈列。
