# Home Style example assets

- `source-room.png` is the original unfinished living room shown by **View Style Example**.
- `result-modern-oriental.png` is the Modern Oriental card preview and example result.
- `result-california-modern.png` is the California Modern card preview and example result.
- `result-maximal-luxe.png` is the Maximal Luxe card preview and example result.

All four images use the same room and an approximately 8:5 landscape composition. They are public demo assets; do not place private customer images in this directory.
