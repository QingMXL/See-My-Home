# Home Layout demo assets

Place the two public demo images in this directory with these exact names:

- `source-plan.png` — the original floor plan shown during Step 2 room confirmation.
- `result-plan.png` — the finished furnished and materialized color layout shown on the result page.

The current room polygons are calibrated to the bundled `700 × 438` source image. The result image may use a different resolution; its room positions should remain proportionally aligned with the source so the UI label overlay stays accurate.

These files are bundled with the public website. Do not place private customer floor plans here.
