# USER — Project-scoped profile

Record only information needed to understand how the household uses the home:

- Preferred language (`en-US` default or `zh-CN`) and display preferences.
- Household composition expressed at the minimum useful level.
- Accessibility or mobility needs the user chooses to share.
- Regular activities by space.
- Storage, work, child, pet, hosting, and privacy needs.
- Retained objects and non-negotiable constraints.
- Budget level only when relevant to prioritization.

Do not assume that an architectural room label equals its actual use. Keep project facts scoped to the current `home_id`.
